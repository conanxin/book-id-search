# 已读网页：按问题查找原文依据

`task_id=BOOK_AI_WEB_SOURCE_EVIDENCE_V1` · 2026-11-13

开发基线为已发布 PR #79 的合并提交 `74fa3677dbb829f5a48abe20b363d600a574cd27`。实现、验证、提交、推送、合并和部署状态分别以对应 PR 最新回执为准。

## 用户流程

用户先在独立 AI 侧栏完成“联网查资料”，再主动读取其中一个来源。读取成功后，可以在“从这篇网页找原文依据”中填写一个问题；默认沿用本次研究问题，允许修改。点击“查找原文依据”才会发起一次模型请求。

模型从这次实际读取的文字中挑选相关片段。页面展示服务器从原文逐字取回的最多四个片段，附来源、读取时间和片段编号；可以定位到当前正文中查看相邻文字，或复制问题、原文和出处。片段编号只对应本次自动提取的网页文字，不是原书页码或网页原有段落编号。

没有选出足够相关原文时，明确显示资料不足，已读取的正文继续可看。提取可能不完整或已截短时，结果继续带相应提示；空选择不代表网页、全书或其他资料没有答案。

## 原文和研究判断的关系

这一步只让模型选择片段编号，事实文字由服务端回填。响应没有自由撰写的答案、版本关系、文章题名或研究结论字段。所选原文可逐字核对，但选段相关性、网页自身的准确性和材料是否完整仍是不同问题。

既有两次自由综合的 `REQUIRES_REVISION` 记录保留：包括把其他著作的方法归给本书、拼接题名、把1935/1937年冲突写成确定初版/再版关系，以及把单一机构的评价扩成学界共识。新增正文或一次选段成功不改变这些历史结论。

## 快照与接口

网页读取接口成功响应新增可选 `snapshotToken`。旧响应没有此字段时，读取、查看和复制功能照常工作；新的选段入口提示重新读取后使用，不自动重读或调用模型。

服务器为成功提取的公开文字保存短期内存快照，绑定书籍、来源编号、原始/最终URL、标题、全文、读取时间和截短状态。凭据为随机32字符base64url字符串，最长30分钟、最多32份快照；重读创建新快照，旧快照内容不会被覆盖。没有数据库迁移或持久内容存储。

```http
POST /api/ai/books/:bookId/research/source/evidence
Content-Type: application/json

{"snapshotToken":"这次已读正文的短期凭据","question":"用户主动提交的问题"}
```

请求只接受上述两个字段，问题去除首尾空格后为1—1,000字符。客户端不上传正文、URL或模型答案；服务器从自己的快照取得文本，不重新抓取网站。

响应合同：

```ts
{
  bookId: string;
  sourceId: string;
  snapshotToken: string;
  question: string;
  mode: "source_passages";
  status: "selected" | "insufficient_evidence";
  requestedUrl: string;
  finalUrl: string;
  title: string;
  fetchedAt: string;
  sourceTruncated: boolean;
  passages: Array<{ id: string; start: number; end: number; text: string }>;
  generatedAt: string;
}
```

`start/end` 为JavaScript UTF-16半开区间，每片必须满足 `text === snapshot.text.slice(start, end)`，不能切断Unicode代理对。服务器先将全文分成最长1,200字符的片段，优先在窗口后半部分的段落或句子边界切分，最多64片，覆盖原文。模型仅返回：

```json
{"passageIds":["P3","P7"],"insufficientEvidence":false}
```

只接受最多四个真实、不重复的片段ID；字段、数量或资料不足标志不一致时拒绝结果。服务器按原文顺序回填。没有候选时返回 `insufficient_evidence` 与空片段列表，不用常识补写。一次操作最多一次提供方调用，没有自动重试、网页重抓或进一步搜索。

客户端核对当前书籍、来源、快照、问题、原始/最终URL、标题、读取时间和截短信息；片段必须是有效整数边界、按原文顺序、不重叠，并与当前正文逐字一致，核对通过才展示和复制。快照凭据不进入复制内容。

## 会话、个人内容与失败处理

沿用Google Owner、Origin、CSRF、no-store和取消机制。改问题、重读、清除、换书、重新联网研究或会话变化后，旧结果和未完成请求失效；迟到响应不能回填。手机侧栏仅收起时，同书同次读取的有效结果继续保留。

模型失败、超时、资料不足和快照过期均不删除已经读取的正文或搜索节选。复制失败提供可手动选择的文字，异步结果不抢走主栏编辑焦点。

模型输入只包含用户为本次选段填写的问题与所选公开网页快照。个人介绍、笔记、微信读书记录和电子版内容不在该服务的数据读取路径；结果没有保存到个人内容的动作。

## 验证范围

定向测试应验证快照TTL与容量、跨书拒绝、全文分片覆盖与Unicode边界、严格ID输出、取消/超时、原文回填及客户端逐字段绑定。1935/1937冲突原句用于回归，产品不得返回编造的初版/再版关系或模型自写文字。

浏览器沿用现有真实会话/CSRF、生产reader和一次性PostgreSQL，外部网页和模型响应使用夹具。覆盖读取、显式选段、定位邻文、复制、清除和手机显示；比较个人资料与未保存编辑，记录个人内容写请求为零。

真实模型选段的结构结果、相关性审阅与真人审阅分别记录。若执行真实试跑，只使用已确认的公开正文和一次明确问题，最多一次模型请求；不把夹具通过当成真实模型效果，也不把组件调用当成真人Google登录后的完整UI旅程。

本阶段开发不包含新PR合并、发布镜像或腾讯云生产切换。未来发布时继续保留PR #79已生效的API DNS配置与现有代理链路。
