# 本书 AI 侧栏：按需读取网页文字

`task_id=BOOK_AI_WEB_SOURCE_READER_V1` · 2026-11-12

基线为 PR #78 合并提交 `6c04c95bdf478b9bae38a2a437039190ff43acd5`。本阶段开发候选、验证提交与发布状态以对应 PR 的最新回执为准。

## 用户流程

“联网研究”已经能实际搜索公开资料，并展示来源提供的搜索节选。用户现在可在某个来源卡片点击“读取网页正文”，取得该网页的可读文字，以便查看节选之外的材料。每次只读取主动选择的一个来源，搜索本身不自动读取所有网页。

成功后，卡片单独显示“网页可读文字（自动提取）”、网页标题、实际读取地址、读取时间和正文；长文字可展开、收起。原来的搜索节选仍保留。网页跳转时，搜索时的地址与最终读取地址都会保留；达到提取长度上限时明确提示已截短。

“复制结果与来源”继续复制本次搜索节选。“复制网页文字与来源”复制这次读取的文字、W 编号、原始与最终链接、时间和截短状态。两者均为只读操作，不进入书籍介绍、笔记、电子版本或微信读书关联的保存流程。

读取失败时保留搜索节选，用户可重试或打开原网页。更改问题、清除结果、重新检索、切换资料范围、换书或退出登录都会取消当前读取并清除对应结果；旧请求不能把内容填回新书或新一次检索。同一书同次检索在手机侧栏收起后仍可继续查看。

## 本阶段提供的能力

| 项目 | 行为 |
| --- | --- |
| 内容 | 公开 HTTP(S) 网页的 HTML、XHTML 或纯文字 |
| 启动 | 来源卡片的主动读取按钮；不会因搜索、显示卡片而开始读取 |
| 提取 | 优先主内容，保留段落；不执行网页脚本，不载入图片或子资源 |
| 展示 | 纯文本；标识自动提取、可能不完整及截短状态 |
| 身份 | 沿用 Google Owner 会话、Origin 和 CSRF |
| 存储 | 当前侧栏内存结果；无数据库迁移或个人内容写入 |
| 模型 | 本次读取不调用模型，不增加 AI 自动综合判断 |
| 边界 | 不读取 PDF/电子书、不登录第三方网站、不代替人工核对网页中的事实 |

这一步扩充可查看的实际来源材料。AI 的现有来源选择仍基于搜索返回的节选，不会把新读取文字冒充为已经由模型分析的研究结论。将正文用于后续提问或跨来源综合是后续开发范围。

## 接口与运行方式

搜索响应中的来源可附带 `readToken`。旧响应缺少该字段时，节选和复制功能照常使用。新接口为：

```http
POST /api/ai/books/:bookId/research/source
Content-Type: application/json

{"sourceToken":"本次来源的短期凭据"}
```

成功响应包含 `bookId/sourceId/requestedUrl/finalUrl/title/text/contentType/extraction/truncated/fetchedAt`。客户端把响应与当前书籍、W 编号和原始链接核对后展示。来源凭据不进入复制文本；过期或 API 重启后，用户重新联网检索即可继续读取。

来源凭据绑定书籍和服务端登记的搜索来源，存活 30 分钟，最多保留 1,000 项。正文读取只接受该凭据，客户端不能提交任意抓取地址。每次请求总时限 20 秒、最多 3 次跳转、响应最多 2 MiB、提取文字最多 30,000 字符。只接受标准 HTTP(S) 端口；逐跳检查公共地址并把连接固定到已核对的 IP，拒绝内网、回环及云元数据地址。

沿用已有服务端 `HTTPS_PROXY`/`HTTP_PROXY` 配置时，通过 CONNECT 连接已核对的目标 IP，原域名用于 Host 和 TLS 验证；不会把用户 Cookie、Authorization 或私人资料转给来源网站。读取器使用 `parse5@7.3.0`，沿用锁文件已有版本，不增加数据库或外部服务。

错误以固定业务码区分无效来源、凭据过期、内容过大、格式不支持、无可读文字、网站不可用和超时；不把网站或连接层的原始错误直接展示给用户。

## 验证与发布

验证涵盖来源凭据与请求边界、正文提取、跳转与连接目标、响应大小/取消/超时，以及侧栏会话隔离和复制。浏览器夹具沿用真实会话/CSRF、生产提取器和本地一次性 PostgreSQL；仅网页和模型的外部网络响应使用合成数据。浏览器会比较操作前后的保存内容和未保存编辑，记录个人资料写请求为零，并保存桌面与手机截图、JSON 回执。

合成网页验证与真实公网读取分别记录。没有真实 Google 登录、真实模型调用或人工内容审阅的步骤，均不得标记为已完成。发布此候选需要同时更新 API 与 Web；不需要迁移、索引设置或新的服务端密钥。本阶段开发不等于已批准发布未来 PR。
