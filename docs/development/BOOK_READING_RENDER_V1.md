# 书籍介绍与笔记：统一阅读呈现

`TASK_ID=BOOK_CENTERED_READING_RENDER_V1` · 2026-10-11

接续 `20eb7dac84ff0d2d76868dfc1d1250e289167c7d` 与累计 [Draft PR #72](https://github.com/conanxin/book-id-search/pull/72)。上一阶段已经能按笔记关键词找回书籍并定位到具体内容；本阶段让这些保存的内容便于阅读，来源链接可以继续打开。

## 目的与范围

此前介绍、当前笔记和历史版本使用普通文本容器；AI 保存草稿已经带有 Markdown 标题、引用摘录及 `[查看来源](...)`，再次打开时仍显示原始标记。本阶段只改善阅读和编辑预览，存储继续使用原有文本与版本接口。

| 位置 | 阅读行为 |
| --- | --- |
| 已保存的书籍介绍、当前笔记 | 用统一排版呈现段落、标题、列表、引用、强调、代码与链接 |
| 笔记历史版本、冲突时读取的最新内容 | 使用同一阅读组件；编辑框中的原草稿继续保留 |
| 介绍与笔记编辑区 | 可展开预览当前输入，明确保存后才写入原有接口 |
| AI 侧栏 | 只读参考结果；查看与复制来源，遵循[AI 助手当前交互](BOOK_AI_ASSISTANT_V1.md) |
| AI 原稿与最新介绍对照 | 使用同一组件；已保存参考资料里的来源链接可以打开 |

微信读书的原始摘录、电子版备注与搜索命中片段继续保留各自的文本语义。电子版仍是外链登记，本阶段不读取 PDF／EPUB 正文。

## 呈现与链接

新增 `BookProse`，接收完整 `content` 字符串并生成 React 元素。使用固定版本 `react-markdown@10.1.0` 与 `remark-gfm@4.0.1`，支持 CommonMark 与表格等 GFM 格式，复用既有颜色、文字和卡片样式。长网址、代码和表格限制在内容区域，手机阅读不拉宽整页。

原文中的换行保持可读；内容标题服从所在书页和笔记层级，不替换页面主标题，也不生成与介绍／笔记外层定位冲突的标题 ID。多块内容中的脚注应指向各自来源。

站内来源保留原路径、查询与片段，并复用上一阶段的具体内容定位。普通 HTTP(S) 外链可点击打开；图片以描述和明确打开入口呈现，不在加载笔记时自动请求图片。HTML 标记作为文字显示；没有 HTML 执行或嵌入页面路径。

预览默认关闭，展开时才呈现当前输入。预览只反映编辑框中的文字，不调用模型或保存内容。取消编辑后再次打开会回到关闭状态。

## 原文与版本

Markdown 解释只发生在阅读层。编辑已有内容仍得到同一份原文，保存提交原字符串；没有后台文本转换、历史重写或数据库迁移。介绍的版本检查、笔记当前修订／历史版本、冲突时保留草稿、切书与 Google 会话边界继续使用既有实现。

`#library-introduction-heading` 和 `#book-note-:noteId` 仍属于外层标题或笔记文章。已保存 AI 来源链接、上一阶段的命中结果链接、刷新及登录返回沿用这些目标。

## 验证与接续

组件测试覆盖实际 Markdown 语义、原文、链接与多块内容的范围；页面测试覆盖编辑预览、明确保存、冲突对照和历史阅读。扩展既有浏览器保存流程，核对 Markdown 保存后刷新仍正确呈现、编辑框保留原文、AI 来源在保存后可点击回到具体笔记。继续使用现有 Book library 工作流，不另建验证流程。

当前提交与实际测试数量记录在 PR #72；桌面／手机截图区分合成夹具和真实用户资料。真实模型试跑仍待原有配置机器执行，当前登记桌面离线。本阶段不合并、发布镜像或部署腾讯云，累计候选继续沿用[增量发布说明](../operations/BOOK_CENTERED_RELEASE.md)。
