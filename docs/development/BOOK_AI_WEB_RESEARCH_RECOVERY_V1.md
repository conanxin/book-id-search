# 联网研究暂停结果恢复

`task_id=BOOK_AI_WEB_RESEARCH_RECOVERY_V1` · 2026-11-13

基于已部署 PR #81 的 `5305e28571f697ddd1a0bd46d690c90521ce3186`，修复书籍详情“联网查资料”在取得搜索结果后仍返回 502 的问题。原始失败、修复候选、真实提供方试验和发布分别记录；具体提交与验收见本阶段 PR。

## 现场原因

用户截图为《梁思成》（林洙著；杨永生主编，北京：中国建筑工业出版社，2012，ISBN 9787112124534），书目 ID `13078447_000008311397`。问题为“查找与这本书主题有关的研究文章和书评资料。”。

2026-11-13 的目标路由访问日志显示三次 HTTP 502。使用实际线上 API 编译模块、容器配置及同一公开书目问题进行一次复现：上游 HTTP 200，搜索阶段 19.462 秒，`stop_reason=pause_turn`，十个完整搜索调用/结果对，随后两个尚无结果的调用。旧适配器仅接受 `end_turn`，故在来源选择之前把整批搜索判成失败；本次选择请求为零。

[MiniMax 服务端工具文档](https://platform.minimax.cn/docs/guides/server-tools) 明确说明，搜索次数达到上限时会以 `pause_turn` 暂停，且没有最终自由文本答案。本产品消费真实搜索片段，并另行选择来源 ID，不依赖这一步的自由答案。

此前 PR #81 的真实组件验收覆盖网页读取与多来源选段，没有覆盖初始实时搜索。既有浏览器夹具一直返回 `end_turn`，因此没有捕获本次暂停形状。

首次修复候选的真实复验已通过搜索阶段：17.035 秒、十次完成搜索、72 个去重来源，正确标记上限。随后来源选择在 0.974 秒返回 `{"sourceIds":["W3","W6"],"insufficientEvidence":true}`。这份矛盾输出被原有严格合同正确拒绝，但同时导致已取得的来源整批消失。该失败保留，并据此补上以下未挑选状态。

## 行为合同

- 搜索消息仅接受 `end_turn` 或 `pause_turn`。顶层错误、失败状态、工具错误、未知/重复结果归属、超限及不完整 JSON 继续失败；`max_tokens` 等其他结束原因不作为有效搜索快照。
- `end_turn` 必须包含至少一个实际搜索，且全部调用都已配对完成。
- `pause_turn` 至少有一个配对完成的搜索；完成调用必须构成发起顺序的前缀，之后仅可有尚未取得结果的尾部调用。这些尾部调用不计作已完成搜索，也不提供来源。
- `queries` 与 `calls` 只统计已配对完成的搜索。所有调用仍受原有十二次上限约束，来源只取对应的 `web_search_tool_result`；生成正文和思考块不成为证据。
- 暂停时向适配器与响应的 `search` 添加可选布尔字段 `limited`，服务端仅在值为 true 时带出。页面兼容未带此字段的旧响应，并拒绝非布尔值。
- 页面保留真实来源卡、查询记录及后续读取入口，显示“本次搜索已达到上限，已保留返回的资料。可以调整问题后再查。”。
- 仍至多一次搜索请求和一次来源选择请求。没有自动续跑、自动重试或新增模型调用；模型、令牌预算、搜索 90 秒及选择 60 秒的期限保持原设置。
- 有有效来源时继续原有严格 ID 选择；来源为空则直接报告资料不足。搜索失败继续报错；选择失败保留来源，不伪装成“资料不足”。
- 来源非空但选择请求失败、超时或响应不符合严格合同，返回 `source=unselected_sources`、空 `citedSourceIds` 和全部已取得来源；矛盾、未知、重复编号不会被使用。固定标题为“待核对的网页资料”，固定说明为“已完成网页搜索，但本次自动挑选未完成。下方保留搜索返回的资料，可以打开原链接核对或读取网页正文。”。
- 页面将这些来源直接展示为“未自动挑选”，保留打开、读取及复制入口；复制全部返回来源与未挑选说明。取消请求、换书或会话变化仍丢弃结果，不进入这个状态。有效的空来源选择仍沿用 `insufficient_sources`。

## 可区分的错误

| 阶段 | 业务代码 | HTTP |
| --- | --- | --- |
| 搜索未完成 | `BOOK_RESEARCH_SEARCH_FAILED` | 502 |
| 搜索超时 | `BOOK_RESEARCH_SEARCH_TIMEOUT` | 504 |
| 搜索请求受限 | `BOOK_RESEARCH_SEARCH_RATE_LIMITED` | 429 |
| 服务或配置不可用 | `BOOK_RESEARCH_UNAVAILABLE` | 503 |

提供方 401/403 不会被映射成用户 Google 登录失效。客户端只为匹配的业务代码和 HTTP 状态展示对应静态提示，不显示上游任意错误文字；HTTP 200 的 JSON/响应合同失败单独说明结果未通过核对。选择失败在已有有效来源时使用上述 HTTP 200 未挑选结果；客户端仍能识别既有来源选择错误码，以兼容分阶段更新。

## 验证范围

定向检查覆盖暂停结果、尾部未完成调用、来源配对与限额、错误分类、前端提示及旧响应兼容。浏览器回归通过真实应用 HTTP、Owner/CSRF、临时 PostgreSQL 和 UI，使用可复现的提供方夹具覆盖暂停来源展示，以及搜索失败后用户主动重试、选择输出矛盾时保留来源。搜索失败期间不能提前调用选择或 reader，问题与未保存个人编辑保留。

真实试验使用本次《梁思成》和截图问题，分别记录实际搜索、来源选择、搜索次数、来源及选择编号。直接服务组件调用不等同于真人 Google OAuth 或登录后的生产浏览器操作。原始失败回执保留，不因修复通过而改写。

本阶段仅涉及 API/Web 与回归夹具，没有数据库迁移、新依赖或基础设施变化。开发候选完成、合并及腾讯云发布以各自实际回执为准。
