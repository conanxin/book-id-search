# 联网来源的题名字样、版本字样与原文上下文

`task_id=BOOK_AI_WEB_SOURCE_TEXT_EVIDENCE_V1` · 2026-11-17 · Draft PR #84

基于已合并并部署的 PR #83，`7cf7297f5c2f29936fe3b6f6f515134c44f5b1cb`。本轮把现有书目文字线索补充为可直接查看的原文上下文。

## 调整原因

原 PR #84 分类候选 `fefdbea76c525a9d23574a38ba7d455652584ac5` 的结构、构建和 CI 均通过，但三轮实际提供方评审仍有关系及资料性质误判：另一部著作《大拙至美》的读后感被称为主题背景，作者采访被称为书评。固定相同来源后也未稳定修复。

这些失败保留在 PR 和 ignored progress 中。本轮移除关系/资料类型模型合同、UI 标签与复制内容，不把减少功能后的验证记作旧分类质量通过。不继续调分类提示或请求提供方；现有 PR #83 的来源选择提示、输入、两键输出与预算恢复原样。

## 本轮提供的能力

- 保留现有 `bookClues` ISBN、完整题名与作者文字摘要，其计算和含义不变。
- 所有返回来源均可携带新的 `textContexts`，独立于是否选中、是否成功自动挑选或资料是否充分。
- 机械识别当前标题或搜索节选中的完整书名号文字，以及约定的明确版本字样，返回有限条原文上下文。
- 不对书名号内文字做繁简、标点、子串或版本合并。书名号也可能包围文章、篇章或文件标题，不能直接称为一本书或另一部著作。
- “再版”“修订版”等只表示原文出现这些字样，不采信来源关于同稿、同书、出版版本的断言。
- 不因线索缺失、不同 ISBN 或题名自动过滤、重排来源或改变选源结果；前十二条有效去重来源的范围不变。

## 响应合同

在每条来源增加独立可选 `textContexts`，原 `bookClues` 保持两键原合同：

```ts
textContexts?: {
  items: Array<{
    kind: "quoted_title" | "edition_text";
    field: "title" | "excerpt";
    value: string;
    matchStart: number;
    matchEnd: number;
    start: number;
    end: number;
    text: string;
  }>;
  limited: boolean;
};
```

`value` 是识别字样，`matchStart/matchEnd` 是其绝对原文范围；`text` 是包含它的上下文，`start/end` 也是原字段的绝对范围。两者均为精确原文切片，且命中范围完全包含在上下文内。

每条来源按标题、节选及命中起点排序；每类最多四项、合计最多八项；上下文不超过 400 个 UTF-16 字符。`quoted_title` 保留完整 `《…》`，内部非空、非嵌套、不跨行、整体最多 120 字符。`edition_text` 仅提取第 N 版、初版、再版、重版、修订版/修訂版、增订版/增訂版、版本、版次等约定原文字样，最多 40 字符。不因为相同字样出现在不同位置就将其合并。

配额、长度限制或已知截短边界导致省略时 `limited=true`，不闭合或复杂的书名号结构保守跳过。新 API 每个来源均返回对象，包括空 `items`；旧响应可缺字段。新增字段不送入 selector，不增加请求或扩大模型上下文。

## 逐字定位边界

位置一律相对于最终返回的原始 `title` 或 `excerpt`，以 UTF-16 范围表示；必须逐字等于对应字符串的切片。上下文和识别到的字样不由模型生成，不从规范化字符串位置反推原文坐标。

标题和节选分别处理，不跨字段拼接，不补全缺失的书名号，不推断未见后文。结果数量和片段长度有界，超过上限须明确标记。无法可靠机械提取的形状保留在原节选中。

客户端再次检查字段、范围、长度、UTF-16 边界和切片一致性，拒绝伪造定位。非法上下文仅使该文字定位区块不可用，原来源、选择状态和读取仍可用；页面与复制共用校验，不改写原始响应。旧响应缺少字段表示未提供此能力；计算后的空结果只表示当前文字未提取到约定字样。

## 页面与复制

所选卡片和全部来源卡片共用同一原生折叠区，展示“书名号中的文字”或“版本字样”及其标题/搜索节选上下文。原完整搜索节选、URL、时间、截短说明与读取入口保留。

范围说明：这里只展示当前标题和搜索节选中的文字线索，不确认同书、版本或资料类型。

复制沿用既有来源集合规则，并包含相同字样、上下文与说明；不包含读取令牌。新增“本书书评”示例仅填写问题：

> 查找直接评论这本书的书评或研究，并提供可核对的网页来源。

这不保证本次一定找到目标书的书评，也不触发自动请求。

原个人介绍、笔记、微信读书内容、电子书及未保存草稿不进入新增处理；展开、复制或查看上下文不请求服务、不写私人内容、不改变已读正文或多来源对照。
