# 联网资料的关系、性质与原文依据

`task_id=BOOK_AI_WEB_SOURCE_RELEVANCE_V1` · 2026-11-17

基于已合并并部署的 PR #83，`7cf7297f5c2f29936fe3b6f6f515134c44f5b1cb`。上一阶段显示当前搜索文字中的书目线索。本阶段在原有一次来源选择调用中，为最多四条所选资料增加“与本书的关系”和“资料性质”两个初判，并由服务器回填判断所据的原文片段。

## 要解决的问题与范围

PR #83 上线后的《梁思成》实测选出另一部著作《大拙至美》的读后感与林洙出版汇总讨论；含目标 ISBN 的商品节选也可能混入杨廷宝文字。本阶段让这些不同关系可见，不通过更换标签宣称已经找到目标书的直接书评。

- 关系与性质分别判断：对应目标 ISBN 的馆藏记录可以是本书书目信息，不能仅凭 ISBN 升级为研究文章。
- AI 初判依据当前返回的标题和搜索节选。原句存在不证明判断正确、资料可信、版本关系成立或已读全文。
- 只判断本轮所选来源。未选或旧响应缺字段表示未判断，不能推断不相关。
- 保持原 source ID、顺序、标题、URL、节选、时间、截短标记、bookClues 和读取令牌；不自动重排、过滤或更新私人内容。
- 搜索仍先保留前十二条有效去重来源。本阶段没有扩大检索覆盖，不能据一次试跑宣称整体检索质量提升。

## 响应合同

在既有响应顶层新增可选 `assessments`：

```ts
assessments?: Array<{
  sourceId: string;
  relationship: "book_candidate" | "other_book" | "related_background" | "unclear";
  materialType: "bibliographic" | "review" | "research" | "discussion" | "other";
  evidence: Array<{
    id: string;
    field: "title" | "excerpt";
    start: number;
    end: number;
    text: string;
  }>;
}>;
```

存在时与 `citedSourceIds` 完全同序、一一对应，最多四条。每条至少一个、最多两个依据，并且至少一个来自 excerpt。原文由服务器回填，不接受模型生成的引文、偏移、URL、解释、可信度分数或额外字段。无所选来源时，若该字段存在必须为空数组。

| 关系值 | 固定展示 |
| --- | --- |
| book_candidate | 可能直接涉及本书 |
| other_book | 其他著作 |
| related_background | 相关主题背景 |
| unclear | 与本书关系待核对 |

| 性质值 | 固定展示 |
| --- | --- |
| bibliographic | 书目或商品信息 |
| review | 书评或读后感 |
| research | 研究性文章 |
| discussion | 讨论资料 |
| other | 其他资料 |

这些标签统一位于“AI 资料判断（待核对）”之下。`book_candidate` 不是同书身份认证；`review` 也可以评论另一部著作。没有 ISBN 的资料不能因此硬编码为背景或不相关，分类仍须依据可见语境。

## 模型合同与证据片段

模型保持原 `sourceIds` 与 `insufficientEvidence`，新增 `assessments`，每项仅有 `sourceId/relationship/materialType/evidenceIds`。证据编号全局包含所属来源，如 `W7:T`、`W7:E1`。标题对应完整标题；节选按自然段或句末优先、必要时按长度连续分段，每段不超过 400 个 UTF-16 字符，完整覆盖可见原文，不拆代理对。

selector 输入的 evidence 数组含 `id/field/text`；标题和完整节选各只出现一次，不再重复发送整份 excerpt。服务器保存片段的真实 start/end，模型只能选择已有编号，返回时按标题在前、节选起点升序回填。不得引用未知、其他来源、重复或仅标题的依据。

固定规则：

- 分类仅来自两个受控枚举；所选来源、顺序、数量和证据归属严格核对。
- ISBN、同作者或人物名字本身不构成“本书书评”的充分理由。
- 书目、馆藏和销售资料保持其性质；跨书、混杂预览、多个版本或讨论对象不明时保留不确定性，不猜出版关系。
- 宽泛主题问题可以选择其他著作或背景。明确只要本书书评而无充分资料时可以正常返回资料不足，仍保留已搜索来源。
- 每次仍最多一次搜索 HTTP 和一次 selection HTTP，原 90/60 秒、selector 1,024 token 与 2,000 字符输出预算不变；无自动重试、续跑或隐式网页读取。

## 兼容与失败

旧 selector 只返回 `sourceIds/insufficientEvidence` 时，沿用原选择并省略新字段，不伪造初判。旧 Web 可继续忽略新增顶层字段；新 Web 接受旧响应缺字段。

新 selector 一旦提供 assessments，就必须完整通过合同；部分、矛盾或损坏的初判沿用既有 `unselected_sources`，保留所有来源、书目线索、搜索记录和读取能力，清空无效选择。取消请求不得变成降级成功。有效不足结果不等于请求错误。

Web 再核对严格键、枚举、ID、完整覆盖与顺序、非空安全整数切片、UTF-16 边界、长度、非重叠和 `text === source[field].slice(start,end)`，拒绝伪造依据。

## 页面和复制

所选卡片与其对应的全部来源卡片共用同一初判块，以原生 details 展开“查看判断依据”，注明标题或搜索节选。展开不请求服务、不重置已读正文或对照选择。未选资料不被隐藏，缺字段不被当作分类失败或不相关。

统一说明：

> AI 根据当前标题和搜索节选作初步判断；原句可核对，判断和资料内容仍需核实。

复制保留同样的初判、说明、逐字依据、原完整节选、URL 与时间，不包含读取令牌。新增“本书书评”预设问题：

> 查找直接评论这本书的书评或研究，并区分其他著作、版本信息与相关背景资料。

原个人介绍、笔记、微信读书内容、电子书及未保存草稿不会进入新增模型输入，不增加私人写入。
