# 本书 AI 联网研究 v1

`task_id=BOOK_AI_WEB_RESEARCH_V1` · 2026-10-11

基线为 PR #73 合并提交 `9ef09095bf34b6b2eedd6363c7163b26d8996699`。本阶段在现有只读侧栏增加实际互联网搜索；提交、测试、真实账户试跑和发布状态以本阶段 PR 的最新回执为准。

## 使用目的

用户找到一本书后，可以围绕内容介绍、研究背景、学术讨论及后续阅读书目提出问题。已有“本书资料”继续整理保存的介绍、笔记与微信读书记录；新增“联网研究”使用当前书目身份和用户主动输入的问题搜索公开资料。

AI 结果留在侧栏。查看来源、复制及清除结果均不保存或修改书籍介绍、笔记、电子版本和微信读书关联。结果不持久化，刷新页面清空。

## 一次联网研究

1. 服务端读取当前书目，选取书名、作者、出版社、年份、页数及 ISBN。
2. 使用既有 MiniMax 配置调用官方服务端 `web_search`，取得实际搜索词和搜索结果。
3. 只把与真实工具调用配对的结果作为来源；为标题、URL 和内容片段分配 W1、W2 等编号。
4. 根据这些来源生成带引用的回答。模型自行写出的搜索声明和网址不作为搜索证据。
5. 侧栏显示回答、实际搜索词、网页链接和取得的片段；复制结果时附带问题、时间及引用来源。

整个过程至多发送一次搜索请求和一次综合请求，无自动重试。工具返回空结果时直接报告资料不足，不发送综合请求；搜索服务失败时显示失败，不退回无来源的常识回答。

第一版不读取用户补充介绍、独立笔记、微信读书记录或电子版本链接。联网问题由用户主动提供。搜索结果里的网页内容始终作为待分析材料处理，其中的指令不会获得系统权限。

## 实现边界

| 项目 | 范围 |
| --- | --- |
| 模型 | 沿用 MiniMax 配置，第一版使用 Anthropic Messages 协议 |
| 搜索证据 | `server_tool_use` 与对应的 `web_search_tool_result` |
| 搜索内容 | 当前书目公开字段 + 本次研究问题 |
| 问题 | 去除首尾空白后 1–1,000 字符 |
| 来源 | 最多 12 项，每项摘录最多 3,000 字符，总摘录最多 24,000 字符 |
| 回答 | 最多 8 段，每段引用本次真实来源；服务器生成 W 编号标记 |
| 登录 | 复用 Google Owner 会话、Origin 和 CSRF 检查 |
| 保存 | 无数据库迁移，无个人内容写入，无 AI 结果自动保存 |
| 页面读取 | 展示提供方返回的搜索结果片段；没有另行抓取网页全文 |
| 电子书 | 不下载或解析 PDF，不声明已经阅读全书 |
| 对话 | 单次问题，没有历史会话或自主多轮研究 |

搜索结果有链接和摘录，不等于已通读网页或验证其中所有事实。页面时间按提供方的原始时间信息展示；检索时间是本次执行时间，二者不混用。当前引用校验检查来源是否真实返回、编号是否匹配；内容是否支持结论还需阅读核对。

## 官方接口依据

- [MiniMax 服务端工具](https://platform.minimax.cn/docs/guides/server-tools)：Anthropic Messages 可声明 `tools: [{type: "web_search_20250305", name: "web_search"}]`；返回搜索调用和搜索结果内容块。能力当前为 Beta。
- [MiniMax Anthropic 接口](https://platform.minimax.cn/docs/api-reference/text-anthropic-api)：MiniMax-M3 的现有兼容协议。

普通生成客户端不会因为调用联网模型而自动执行搜索。新适配器显式声明工具、解析实际执行记录；原有资料整理接口保持原行为。

## 接口

`POST /api/ai/books/:bookId/research`，请求体 `{ "question": "研究问题" }`。

成功响应包含 `bookId/question/source/draft/sources/citedSourceIds/search/generatedAt`。`source` 为 `web_research` 或 `insufficient_sources`；`sources` 中每项包含 `id/kind/title/url/excerpt/pageAge/truncated`。`search` 保留 `performed/queries/calls`。错误响应使用静态业务错误，不回传模型密钥或提供方原始错误。

## 验证与接续

定向检查包括真实工具记录解析、工具缺失与错误、空结果、未知引用、资料截断、登录和请求取消、来源展示、带来源复制，以及 AI 使用期间个人资料与未保存编辑不变。浏览器夹具模拟提供方网络响应，不能代替真实搜索试跑。

真实试跑命令：

```bash
corepack pnpm exec tsx scripts/book-web-research-live-trial.ts \
  --book-id 10118949_000001131331 \
  --query '中国古代旅行之研究' \
  --question '查找这本书的内容介绍、相关研究与后续阅读资料，并区分书目事实和研究评价。' \
  --out progress/book-web-research-live
```

命令使用公开搜索响应中 ID 精确匹配的书目和进程继承的 MiniMax 配置，不连接 PostgreSQL、不修改生产服务。回执分别记录真实搜索请求、综合请求及来源；结构通过与内容审阅状态分开。

本阶段开发不包含生产发布。候选需更新 API 与 Web；现有数据库、Google 配置及手工内容不需迁移。发布前确认实际 MiniMax 账户能够使用搜索功能，且来源与回答可核对。
