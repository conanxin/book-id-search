## STATUS: PASS

All release gates passed. No rollback required.

---

## SCOPE

- **Source**: already-computed `WereadReadingEraResult` (produced by
  S27M from the in-memory `WereadReadingArchive`). No additional fetch,
  no new route.
- **Output**: browser-local `.md` file generated by pure functions and
  downloaded via a transient `Blob` URL + `<a download>` click.
- **Network**: zero additional annual-review / AI summary /
  related-books requests triggered by the export button or mode/range/Top
  N changes.
- **Persistence**: nothing written to `localStorage` / `sessionStorage` /
  `IndexedDB`; nothing POSTed to the server; no external service called.

---

## MARKDOWN_RESULT

- **Header metadata**: archive year range, current range label, Top N
  scope, segmentation mode, success/failed year counts, era count,
  export timestamp, generation method, and save-state note.
- **Privacy / interpretation notes**: fixed disclaimer that the file is
  generated locally, contains public catalog info + personal reading
  statistics, and should be kept safe; plus a fixed boundary
  interpretation note. No psychological / interest / personality /
  quality language.
- **Completeness note**: when `failedYears.length > 0`, a warning states
  the segmentation is based only on successfully loaded years; when all
  years succeeded, a data-integrity note is shown instead.
- **Phase overview table**: phases in chronological order with year
  range, year count, total records, total active months, average records
  per year (≤1 decimal), and peak year + records.
- **Phase details**: each phase lists its years, counts, average, peak
  year, and (for non-first phases) the boundary before it with score
  and allow-listed Chinese reasons.
- **Phase recurring books**: up to 6 books that appeared in the current
  Top N in at least two phase years, with public title, author,
  publisher/publishYear, years on list, best rank, latest year, and a
  public `/books/:catalogId` URL. Missing fields are omitted.
- **Boundary overview table**: all boundaries with score and reasons; or
  a neutral fallback when no boundaries exist.
- **Method notes**: 13 deterministic rule statements explaining how the
  segmentation is computed and what it does not claim (no theme / category
  / psychological / personality / interest / quality analysis; no note
  text read; no external AI called; no upload or server save).
- **Empty archive**: keeps metadata, privacy note, interpretation note,
  completeness note, and method notes; phase overview/details/boundary
  sections are not emitted.
- **Single-year archive**: one phase with all stats, no boundary section,
  empty recurring books, and a note that adjacent-year comparison is not
  possible.

## BOUNDARY_RESULT

- Boundary reasons are rendered using the four allow-listed Chinese
  labels only:
  - `年份存在中断`
  - `阅读记录数量变化较大`
  - `活跃月份数量变化较大`
  - `相邻年度 Top N 榜单重合较低`
- Boundary score and position are included in both the phase detail
  section and the boundary overview table.
- No boundary section is emitted for single-year or empty archives.

## PARTIAL_AND_EMPTY_RESULT

- **Partial failure**: export button remains enabled; the header includes
  the failed-year count and a completeness warning; segmentation is based
  only on successfully loaded years. After retry succeeds, the
  completeness warning disappears and the data-integrity note appears.
- **Empty archive**: export button remains enabled after bootstrap; the
  file contains only metadata, privacy note, interpretation note,
  completeness note, and method notes.
- **Single-year archive**: one phase with all stats and a note that no
  adjacent-year comparison is possible.

## FILENAME_AND_MIME_RESULT

- **Automatic**: `weread-reading-eras-automatic-<first>-to-<latest>-YYYYMMDD.md`
- **Gaps-only**: `weread-reading-eras-gaps-only-<first>-to-<latest>-YYYYMMDD.md`
- **Empty**: `weread-reading-eras-<mode>-empty-YYYYMMDD.md`
- All filenames are ASCII only and capped at 80 characters.
- MIME: `text/markdown;charset=utf-8`.
- File generation uses `Blob` + `URL.createObjectURL` + a temporary
  `<a download>` element + `URL.revokeObjectURL` on the next tick.

## LIMITATIONS

- Hard cap of **20 years** (`READING_ARCHIVE_MAX_YEARS`).
- Phase recurring books only consider the **current Top N** (6 / 12 /
  18), not the full yearly catalog.
- Boundary thresholds are heuristic and not user-configurable.
- The exported Markdown is a static snapshot; it does not auto-update
  when the archive changes.
- Browser download behavior depends on the user's browser settings;
  the file is not pushed to any server.
