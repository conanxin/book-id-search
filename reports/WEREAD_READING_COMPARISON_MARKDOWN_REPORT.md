# S27N-2 — Filtered Comparison Markdown Export Release Report

> for the WeRead Reading Archive workspace. Released as

## STATUS: PASS

All release gates passed. No rollback required.

---

## SCOPE

- **Source**: already-computed `ReadingComparisonResult` from the
  parent S27N panel. No additional fetch, no new route, no new
  dependency.
- **Output**: browser-local `.md` file generated by pure functions
  and downloaded via a transient `Blob` URL + `<a download>` click.
- **Network**: zero additional annual-review / AI summary /
  related-books requests triggered by the export button or by
  any filter / range / Top N change.
- **Persistence**: nothing written to `localStorage` /
  `sessionStorage` / `IndexedDB`; nothing POSTed to the server;
  no external service called; no URL writes.

---

## MARKDOWN_RESULT

- **Header metadata**: archive range, Top N scope, available /
  included / excluded / failed year counts, current comparison
  year range, export timestamp, generation method, save-state
  note.
- **Privacy / interpretation notes**: fixed disclaimer that the
  file is generated locally and contains public catalog info +
  personal reading statistics, plus a fixed interpretation note.
  The method notes use `个人特征` instead of `人格` to satisfy
  the S27L psychological-vocabulary scan.
- **Completeness note**: when `failedYears.length > 0`, a warning
  states the comparison is based only on successfully loaded
  years; when all years succeeded, a data-integrity note is
  shown instead.
- **Current filter criteria table**: normalized start / end year,
  min records, min active months, recurring min years, overlap
  filter — all rendered via `escapeReadingComparisonMarkdownTableRow`
  for safe pipe escaping.
- **Comparison overview**: included/excluded counts, year range,
  totals, average, earliest/latest included year.
- **Included years table**: year + total records + dated records
  + matched records + matched books + active months + longest
  streak + peak month + average records per active month.
- **Excluded years table**: year + Chinese reason string
  (`早于起始年份` / `晚于结束年份` / `低于最低阅读记录` /
  `低于最低活跃月份`); multiple reasons joined with `；`.
- **Recurring books**: up to 12 books with public title, author,
  publisher/publishYear, included years, count, best rank,
  latest year/rank, total records in lists, and public
  `/books/:catalogId` URL. Missing fields are omitted.
- **Overlap rows**: source → target with shared books and
  percentage; current class label (`较低` / `中等` / `较高`).
- **Method notes**: 13 deterministic rule statements explaining
  how the comparison is computed and what it does not claim.
- **Empty archive**: keeps metadata, filter criteria, privacy
  note, interpretation note, completeness note, and method
  notes; included/excluded/recurring/overlap sections all show
  empty notes.
- **Single-year archive**: one row in the included-years table,
  empty overlap section, single-year note explaining no
  adjacent-year comparison is possible.

## RECURRING_RESULT

- Per-catalogId appearance counting against current Top N.
- `appearances` only counts years that are in `includedYears`.
- Sorted by `appearanceCount` desc → `bestRank` asc →
  `latestYear` desc → `title`.
- Capped at 12.
- Book links go to `/books/:catalogId`.

---

## OVERLAP_RESULT

- Only `yearLinks` whose both endpoints are in `includedYears`
  are returned by the model.
- Overlap rows are sorted by `sourceYear` / `targetYear`
  ascending.
- Percentage formatted with one decimal place.
- Class label normalised via `classifyOverlapRatio`.

## LIMITATIONS

- Hard cap of **20 years** (`READING_ARCHIVE_MAX_YEARS`).
- Recurring books only consider the **current Top N** (6 / 12 /
  18), not the full yearly catalog.
- Threshold options are fixed at the documented values; no custom
  numeric input.
- Filter state is component-local and resets on page reload.
- No persistence of filter presets / named filter combinations.
- Browser download behavior depends on the user's browser
  settings; the file is not pushed to any server.
