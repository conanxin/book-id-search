# PREF-EXP-1D3 Blind Semantic Fit Review

Purpose: calibrate retrieval semantic validity before any human Preference Sovereignty pilot.

The generated review package intentionally hides:
- the original search seed from each candidate row;
- the original retrieval rank.

The reviewer sees only:
- a neutral research-intent code and legend;
- public bibliographic metadata;
- a fixed semantic-fit rubric.

The answer key is uploaded as a separate artifact and should not be opened before review completion.

This stage is read-only against books.conanxin.com and does not use private WeRead data, LLM calls, online learning, or production writes.
